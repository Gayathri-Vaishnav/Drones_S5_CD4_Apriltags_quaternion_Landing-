# Sibling simulator review (documentation-level)

Reviewed the README files in `../webots/` and `../3D simulation/` on 2026-10-22 to honor the request to check the other simulations. Their result folders and source files were not modified.

| Project | README-described model and timing | Capabilities and evidence boundary |
|---|---|---|
| PyBullet (this project) | Procedural rigid body; fixed step 1/120 s; low-level control 120 Hz; mission/guidance 30 Hz; camera 10 Hz at 640×480 by default; TinyRenderer in DIRECT and hardware OpenGL requested in GUI. | Ten address targets and tag detection. New 600-step smoke is not a landing result; no aggregate success benchmark yet. |
| Webots (`../webots/`) | Webots PROTO/controller with a 16 ms basic time step; onboard camera, GPS, inertial unit, gyro and motors. | Its setup scripts and doctor are now present; running `python doctor.py --skip-runtime` from the Webots root passes 8/8 checks and finds Webots. The existing `.venv` is unusable because its `pyvenv.cfg` points at a removed Python 3.12 executable. I added a guard to both setup scripts to archive that unusable environment before recreating it. Package reinstall was not run because network access is unavailable. README lists moving-truck landing, wind controls, simulated battery/geofence/tag/acquisition failsafes, RTH, and telemetry/event/detection/timing logs. Historical results are not new evidence. |
| MuJoCo (`../3D simulation/`) | Free-body model; README describes 0.002 s physics, 0.02 s control, 0.04 s thrust lag, synthetic camera with noise/blur, and optional correlated wind. | README lists static/dynamic workflows, multi-target vision, failsafe telemetry, and timestamped logs. It notes stochastic wind uses NumPy's global RNG, so enabled wind is not reproducible across runs. No fresh comparison trial was run. |

The three projects use different vehicle models, timestep, controllers, camera models, target handling, and simulator contacts. Their historical CSVs and README claims cannot be combined as a benchmark. A first shared schema and two JSON-compatible YAML scenario fixtures now live under `../scenarios/common/`; the PyBullet batch runner consumes them with the Python standard library. Webots and MuJoCo have not been adapted to load these fixtures, and fresh qualitative comparison runs remain unimplemented. Numeric equivalence is explicitly not claimed.
